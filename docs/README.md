# Documentación

Carpeta para toda la documentación extendida del proyecto que no encaja en el `README.md` principal: diseño de la arquitectura del modelo, decisiones técnicas, resultados de experimentos, referencias bibliográficas, diagramas, etc.

## Sugerencia de organización

```
docs/
├── arquitectura.md       # Diseño del modelo / pipeline
├── experimentos.md       # Registro de experimentos y resultados
├── referencias.md        # Papers, datasets y recursos utilizados
└── img/                  # Imágenes y diagramas usados en la documentación
```

No es obligatorio seguir esta estructura exacta: adáptala a las necesidades de cada proyecto (CNN, RNN, RAG...).
