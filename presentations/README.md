# Presentaciones

Carpeta para guardar las presentaciones (slides) usadas en exposiciones, entregas o defensas del proyecto (`.pdf`, `.pptx`, `.key`, etc.).

## Convención de nombres

```
2026-01-15_presentacion-final.pdf
2026-02-03_avance-entrega1.pptx
```

## Nota

Los formatos binarios de presentaciones (PDF, PPTX...) sí se versionan en Git con normalidad, ya que no forman parte de los artefactos pesados excluidos en el `.gitignore` (datos y modelos entrenados). Aun así, evita subir archivos innecesariamente grandes (vídeos incrustados, etc.).
